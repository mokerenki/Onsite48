# Email Drafting Skill

## Rules
- Prefer draft tools over send tools until the user confirms.
- Subject line: specific, under 70 chars when possible.
- Body: purpose in first sentence; action items as bullets; polite close.
- If data is needed from workspace files, read them first and quote accurately.
- Attachments: produce files in workspace, then attach via the connector draft API.

## Structure template
```
Subject: ...

Hi <Name>,

<1–2 sentence purpose>

- Action / detail 1
- Action / detail 2

Thanks,
<Sender>
```
